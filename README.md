# 🌴 Blue Palm Traveling – Landing Page

Site de promoção de packs de viagem com design moderno e integração com WhatsApp.

## ✨ Funcionalidades

- Landing page responsiva com Tailwind CSS
- Cards interativos para 4 packs de viagem
- Botões que geram mensagem personalizada para WhatsApp
- Design alinhado com a identidade da marca "Blue Palm Traveling"

## 🛠️ Tecnologias

- Python + Flask
- Tailwind CSS (CDN)
- Vercel (deploy serverless)

## 🚀 Como executar localmente

1. Clone o repositório
2. Crie um ambiente virtual (opcional)
3. Instale as dependências:
   ```bash
   pip install -r requirements.txt
